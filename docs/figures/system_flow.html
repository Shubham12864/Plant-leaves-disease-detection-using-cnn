2. One request, end to end

The browser never holds a model. It holds a drop zone and a canvas.

sequenceDiagram
    autonumber
    participant B as Browser
    participant A as FastAPI backend
    participant M as PyTorch model
    participant H as Grad-CAM hooks

    B->>A: POST /api/predict with the image file
    A->>A: resize 224, to tensor, normalise with checkpoint mean and std
    A->>M: forward pass
    M-->>A: 38 logits
    A->>A: softmax, pick top 1 and top 3, compare against threshold 0.70
    A->>M: backward pass on the winning class score only
    H-->>A: activations and gradients from last conv layer, 7x7
    A->>A: weight channels by mean gradient, ReLU, upsample 224, blend over photo
    A-->>B: JSON with label, top 3, heat map PNG, timings, warnings
    B->>B: paint result card, probability bars, heat map slider
