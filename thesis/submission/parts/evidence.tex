\section{Reproducing the numbers}

\begin{verbatim}
# regenerate the reported tables and verify every claim
python scripts/build_tables.py
python scripts/build_tables.py --verify

# all checks in one command
python scripts/run_all.py --check

# intervention experiment
python scripts/swap_localisation_test.py \
    --checkpoint checkpoints/efficientnet_b0/best.pt \
    --limit 300 --out reports/mechanism/swap_test_b0

# field evaluation of a checkpoint
python scripts/evaluate_plantdoc.py \
    --checkpoint <path>/best.pt \
    --arch efficientnet_b0 --out <dir>
\end{verbatim}

Model weights and datasets are not stored in the repository; the commands that need
them expect the files at the paths shown.

\section{Statement on scope}

This submission reports measured results. It does not claim field readiness, clinical
or agronomic reliability, or a deployed system. The field evaluation rests on 236
images from a single source, and the reported accuracy on that set is low enough that
no operational use is justified. What the work establishes is what a clean-image
classifier is worth under field conditions, and why.
