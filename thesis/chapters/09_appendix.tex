\section{Compute}

All training ran on Kaggle with two Tesla T4 GPUs. Local hardware was used for data
preparation, evaluation of returned checkpoints and document generation. No training
was performed locally.

\section{Commands}

\begin{verbatim}
# training (Kaggle, generated notebook)
python scripts/build_s19_notebook.py

# evaluate a checkpoint on PlantDoc
python scripts/evaluate_plantdoc.py \
    --checkpoint <path>/efficientnet_b0_best.pt \
    --arch efficientnet_b0 --out <dir>

# intervention experiment
python scripts/swap_localisation_test.py \
    --checkpoint checkpoints/efficientnet_b0/efficientnet_b0_best.pt \
    --limit 300 --out reports/mechanism/swap_test_b0

# regenerate tables and check every quoted number
python scripts/build_tables.py
python scripts/build_tables.py --verify

# build this document
python scripts/build_thesis.py
\end{verbatim}

\section{Version control}

The repository is under Git. Each experiment is committed with the command that
produced it and the artifact directory it wrote. Checkpoints are not committed;
their SHA-256 hashes are, in `reports/s19/checkpoint\_hashes.json`.
